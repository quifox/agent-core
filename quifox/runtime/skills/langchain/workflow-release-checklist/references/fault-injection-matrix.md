# 工作流风险场景覆盖与可选验证方法

这里是**可供挑选的场景库**，不是 30 项必跑测试。使用时先确认某项问题在当前工作流中是否可能发生。对于不存在的功能、不可达分支或代码已足以判断的简单情形，直接跳过或给出代码层面的说明即可。

验证可以有不同深度：

1. **代码阅读**：看入口、错误分支、调用契约、State 持久化时机。某种路径根本不存在时，无须专门写测试。
2. **已有测试**：如果仓库已经覆盖此行为，优先复用对应测试结果。
3. **轻量模拟**：值得进一步确认时，用 Mock、Stub 或隔离代理制造有限的错误。
4. **故障演练**：只对确实要求跨进程恢复、真实外部副作用等高风险场景，在获授权的隔离环境中进行。不能安全执行就保留建议。

以下“可选模拟”不是执行指令；是否模拟由任务目的、风险、时间和环境决定，不要为了凑覆盖率创建测试工具或改动生产代码。

## A. 工具调用与模型服务

| 场景 | 何时需要关注 | 先从代码或已有测试看什么 | 如有必要可怎样模拟 | 重点观察 |
| --- | --- | --- | --- | --- |
| F01 工具超时 | 调用耗时不确定的外部工具 | 超时与取消传播、调用预算 | Stub 故意延迟到 deadline 之后 | 不无限等待，能给出明确失败或降级 |
| F02 限流 429 | 调用可能限流的远端服务 | 重试次数、退避、Retry-After | Stub 返回 429，再恢复正常 | 不形成重试风暴 |
| F03 5xx 与断连 | 工作流依赖远端工具 | 异常与状态是否正确向上传播 | Stub 返回 503 或中断连接 | 不把错误伪装成成功 |
| F04 参数或 Schema 错误 | 模型可能生成工具参数 | 入参验证与错误映射 | 输入缺字段、错类型的参数 | 不无谓重试，模型能获知准确错误 |
| F05 写成功但响应丢失 | 有外部创建、更新等副作用 | 幂等键、结果查询、未知状态分支 | Stub 记录写入后丢弃确认 | 不重复产生业务效果；不能判断则标记结果未知 |
| F14 模型无效输出 | 模型输出需满足 JSON/Schema | 结构化解析、校验和修正边界 | Stub 返回错误 JSON 或漏字段 | 有界处理，不静默接受无效结果 |
| F15 模型接口不稳定 | 调用受限流或网络影响的 LLM | 模型调用重试、超时、花费上限 | Stub 延迟、429 或连接失败 | 不无限请求或超支 |
| F16 工具输出过长 | 外部工具可返回大段文本 | Token/内容大小限制和截断规则 | 返回超长工具结果 | 不突破上下文预算，必要证据得到保留 |
| F23 模型与工具成本 | 存在循环推理或付费调用 | 最大步骤、Token 与费用预算 | 让测试 Agent 多轮调用工具 | 成本有界，有停止原因 |

## B. 状态持久化、中断与恢复

| 场景 | 何时需要关注 | 先从代码或已有测试看什么 | 如有必要可怎样模拟 | 重点观察 |
| --- | --- | --- | --- | --- |
| F06 进程宕机 | 需求明确包含跨进程续跑 | 是否使用持久 Checkpointer、谁重新调度 Run | 在隔离环境的选定节点停止测试 Worker，重启 | 从正确的已持久化边界恢复 |
| F07 Checkpoint 前的副作用 | 外部写操作与持久化步骤分离 | 副作用调用与 Checkpoint 的先后顺序 | 写入成功后、下一次状态提交前中断 | 幂等或结果确认成立，不假设恰好一次 |
| F08 Checkpointer 不可用 | 实际使用数据库等持久化后端 | 存储失败能否传播、确认时机 | 隔离环境中让测试存储超时或拒绝写入 | 不假装状态已安全保存 |
| F09 状态格式损坏 | 持久任务长期存在或会升级 Schema | 解码校验、兼容迁移与错误路径 | 读取不匹配版本的合成 State | 清晰失败或安全迁移 |
| F10 并行部分成功 | 工作流存在并行分支并要求续跑 | Reducer、完成状态和恢复合同 | 让 A 完成而 B 出错后重启 | A 结果保留，B 按策略重试，汇总不串线 |
| F11 多 Worker 竞争恢复 | 多 Worker 可能领取同一 Run | 租约、条件更新、运行身份校验 | 用两个隔离 Worker 争抢同一测试任务 | 没有错误接管或重复业务副作用 |
| F12 人工审批中断 | 工作流包含 HITL 审批 | 审批状态、身份绑定、恢复参数 | 在审批后重启测试 Worker | 审批不会丢失或被用于其他操作 |
| F13 取消和终止 | 有异步、长耗时或子 Agent 任务 | Abort/取消传播、资源释放与状态标记 | 正在执行工具时取消测试 Run | 子任务及时结束或受控收尾 |
| F25 工作流版本变更 | 旧 Run 可能跨版本继续 | 版本绑定、State 迁移、回滚方案 | 保存旧版 Run，再用候选版本尝试恢复 | 保持兼容或明确拒绝，不错误续跑 |
| F27 无法终止的循环 | 允许循环、工具规划或动态 Agent | 迭代/递归次数、时间和预算上限 | Stub 让结束条件始终不成立 | 到限制时安全停止并报告原因 |

## C. RAG、证据与权限

| 场景 | 何时需要关注 | 先从代码或已有测试看什么 | 如有必要可怎样模拟 | 重点观察 |
| --- | --- | --- | --- | --- |
| F17 多索引检索部分失败 | 一次查询聚合多个检索来源 | 各索引错误是否被吞掉 | Stub 让一个索引正常、另一个异常 | 不把部分结果错误地当作完整成功 |
| F18 空结果和重复证据 | 工作流消费 RAG 或网页证据 | 证据 ID、去重、空结果与失败语义 | 返回重复段落、空命中或重排结果 | 引用正确，不错认失败为无资料 |
| F19 跨租户状态访问 | 用户、租户之间共享服务与存储 | 访问检查是否在可信服务端执行 | 使用两组测试身份请求彼此的 Run | 不能跨范围读取、修改或续跑 |
| F20 提示注入和越权调用 | 使用不可信文档或工具返回值 | 模型权限与实际工具授权是否分离 | 让模拟文档包含越权指令 | 提示词不能越过执行层权限边界 |
| F28 敏感信息泄露 | 处理凭据、个人信息或客户数据 | 日志、Trace、异常信息的脱敏 | 使用合成敏感字段贯穿一次测试 Run | 输出、记录和工具反馈不泄露敏感字段 |

## D. API、部署及运行观测

| 场景 | 何时需要关注 | 先从代码或已有测试看什么 | 如有必要可怎样模拟 | 重点观察 |
| --- | --- | --- | --- | --- |
| F21 API 重放 | 发布可产生副作用的 API | 请求幂等键与重复提交语义 | 重复发送相同测试创建请求 | 行为符合幂等合同 |
| F22 限流与背压 | 对外提供高并发或付费 API | 速率限制、队列上限和拒绝策略 | 在隔离环境逐渐增加并发 | 延迟和资源消耗受控，能明确拒绝 |
| F24 客户端断线重连 | API 提供长任务或事件流 | Run ID、重连游标、状态查询 | 测试客户端中途断线后重新连接 | 访问同一运行状态，不无故重复任务 |
| F26 存储/队列抖动 | 运行依赖数据库、消息队列等外部基础设施 | 超时、恢复与重试逻辑 | 测试代理增加延迟或短时断开 | 失败被正确表达，恢复后能继续 |
| F29 追踪链路异常 | 依赖外部观测服务 | 观测失败是否错误影响主路径 | 关闭隔离环境的测试 Trace Exporter | 主执行符合既定策略，仍有基本排障线索 |
| F30 版本回滚 | 有部署、版本切换和数据迁移 | 代码/Schema 兼容、回滚步骤 | 在测试环境从候选版本切回稳定版本 | API、State 和存量 Run 不产生隐蔽错配 |

## 选择时的几个例子

- **只读、单轮、本地执行的 RAG 脚本**：重点看 F01/F03/F14/F17/F18；没有对外 API、持久恢复或写副作用时，其他大量场景可直接略过。
- **长时间运行的 LangGraph 多 Agent 工作流**：可优先关注 F06/F08/F10/F11/F13/F25。是否做真正宕机演练，取决于是否承诺进程重启后恢复，以及现有测试能否提供足够证据。
- **带外部写操作的服务化工作流**：可优先关注 F05/F07/F19/F21；若出现“写成功但状态未知”的窗口，建议优先确认幂等机制。

## 结论应如何表达

不需要对 30 项打分。可简要说明：

- **代码已能确认**：引用具体实现、配置或已有测试；不再重复模拟。
- **值得提醒**：说明问题在什么条件下出现，以及可能的后果。
- **可选验证**：如果缺乏证据且影响较大，给出一个成本合适的 Mock、集成测试或隔离故障演练办法。
- **没有必要验证**：当代码结构或业务约束已经排除风险时，不为覆盖数字补测。

破坏性实验只在经过确认的隔离环境进行。以上内容既不证明任何工作流已生产就绪，也不代表必须构建自动化测试器。
