# QuiFox 共享 Host

## TypeScript 工作流

工作流由独立 WorkflowToolsPlugin 与 WorkflowModelPlugin 接入；Host 拥有脚本库、编译、子进程与 Agent 装配。私有应用包 workflow-engine 派生自 ZCode，固定来源版本并保留 Apache-2.0 LICENSE/NOTICE；不修改 Core。脚本使用普通 TypeScript 与 agent().ask()；具名方法必须使用 JSDoc `@node` 或 `@phase` 提供节点标签。匿名回调可作为所属节点的实现细节；入口自动成为根节点。图从同一 TypeScript Program 的 AST/类型符号解析调用关系，不要求作者编写边、节点身份或独立图定义。

初始图表达可解析的调用关系，不宣称是执行顺序或本轮必经路径。条件、循环与回调关系保留语义；不能静态解析的动态派发不虚构边，实际进入已标记方法时补充真实调用边。运行插桩保持方法的参数、this、同步/异步返回与异常语义；每次调用有独立身份与父调用身份，异步上下文隔离并行分支，不能用单个全局阶段变量判断归属。同一方法定义只展示一个节点，默认汇总本轮调用次数与状态；可展开实际调用实例。静态未调用节点只表示尚无本轮调用事实，不被解释为失败、跳过或未知执行结果。运行事实持久化到已有 Session journal；重放与新的回合使用不同执行身份，UI 不混合旧轮次与新轮次。

支持层拥有脚本检查、加载、执行、检查点、插件绑定与图投影；生成脚本的业务逻辑由脚本作者负责。检查失败给出诊断，不自动改写意图、分支、提示词或业务行为。运行模板是示例，不是自动生产保证。所有执行及检查点故障事件携带相同执行身份；迟到的旧执行事件不能改变新执行状态。工作流收尾取消尚未结束的调用，缺少返回事件不被推断为调用失败；只有明确的异常返回使该调用标记失败。

脚本库位于应用资料根 workflows/*.ts；保存前检查，名称限制为单层文件名，读写拒绝符号链接。已有会话固定保存其所运行脚本，更新文件不静默改变历史会话。每次工作流回合创建空上下文的内部 Agent，同一 actor 的多次 ask 复用该回合的会话；外层会话只把 user/assistant 输入输出传入 args.messages。内部 Agent 复用共享 Host 的模型、授权、工具、观察与持久化，不能递归启动工作流或子 Agent，工具权限不能超过外层。

工作流插件绑定 typescript-workflows Skill，由既有 Skills catalog 自动发现；skill_load 渐进加载正文，skill_read 读取动态业务插件目录、恢复说明与模板，基础设施不重复展示。通用 KnowledgePlugin 暴露 knowledge_retrieve，Host 注入本地 Mock 检索回调，不绑定外部后端、连接或密钥。Mock 插件默认不安装；显式安装启用后可直接调用，也可通过 agent(name, {plugins:["knowledge"]}) 使用。示例按固定中英文关键词匹配合成资料，可按 documentIds 缩小范围，资料与来源明确标记 Mock；未匹配返回空结果，不伪装真实检索质量。tools 可缩小内部 Agent 的工具范围，但不能扩大父权限。脚本不接触密钥、Node 模块或 fetch。运行事件沿已有 Session journal 保存并投影节点状态；停止覆盖子进程与所有内部工具。脚本执行隔离用于本地受信工作流，不承诺 Node VM 是安全边界。

引擎检查点保存到资料根 workflow-runs，节点结果写入并 fsync 后才向脚本返回，按脚本、输入身份与原 actor 身份恢复。恢复从入口重放确定性控制流，已完成节点复用原结果；内部 Agent 接回自己的 Session。未知工具结果由既有 replan 补齐未知/打断回执，不静默重试副作用，不承诺外部 exactly-once。本地检查点不包含任意 JavaScript 堆，模板应使用稳定 args 和具名 actor；无相应业务幂等协议的写入不能靠模板宣称安全。模板包含只读检索重试与并行汇合，当前恢复与平台故障边界通过真实行为测试单独验证。

检查点按会话、外层输入、调用身份与脚本/参数身份隔离；工具调用使用已有持久化 operationId，区分同一回合内参数相同的不同调用及不同工具批次的重复 call ID，恢复沿用原身份。工作流会话的模型入口使用外层输入身份。只保留当前外层输入的检查点，新输入已持久化接纳后清理该会话更早输入的检查点及生成执行体。包含输入的生成执行体只写入私有应用资料根；内部 Agent 的工具仍使用实际工作目录。同一输入内的多个工作流调用均可重放。WAL 写入、同步或关闭失败后停止后续持久化与业务推进，记录本地诊断；不能发布成功。恢复仅丢弃不完整尾行，闭合损坏行明确失败。

显式部署保存的工作流启动 Bearer 认证的本机 HTTP 服务，复用同一 Host 命令与会话；POST /runs 接受 question/可选 sessionId，GET /runs/:id 查看结果，POST /runs/:id/stop 停止。按工作流名称与工作目录唯一部署，重复请求返回同一服务，运行固定使用部署时脚本。Token 只在显式管理回执中提供，不进入配置、事件、服务目录和普通快照；只读访问限于该部署创建的会话。关闭弹窗只隐藏管理面板，停止 API 命令关闭其连接与运行。服务随 Host 关闭，不自动绑定公网，不宣称已有远程生产部署平台。

本 Host 提供 TUI 与 Tauri/Bun sidecar 的唯一能力入口，组合原 Core 和插件；UI 只提交命令并读取带会话/运行/序列身份的真实事件。Core 源码不变，当前仅装配 Chat Model。

子智能体创建默认空历史，模型工具仅显式 mode:fork 时复制父上下文；`/spawn` 同样默认空历史，`/spawn --fork` 才复制安全前缀。首期只允许主会话创建一层子 Agent：子会话不装配 subagent_start，Host 创建入口也拒绝后代创建，不新增递归深度配置。子请求的 agent-role 贡献明确其真实名称、taskId 与父会话身份，继承历史仅为背景；子文本不被用来判断任务身份。wait 回包的 taskId/name/status 来自插件记录，text 保留原始子回复。

用户停止覆盖当前会话及其子任务树，向模型、前台工具、后台任务与子 Agent 发出取消；等待工具及时响应取消，不等待原超时。取消中的前台工具交回实际收尾结果，后台操作收尾和子任务树结束前不开放恢复；不能以合成回执先行宣称实际进程已经退出。与停止交错的子任务创建不得在停止后启动。已完成回执保留；停止后为仍未闭合的工具调用补齐未执行或已打断回执并与 Session 配对保存，不宣称副作用已回滚。QuiFox UI 只提供一个恢复操作，默认走现有 replan；通用插件的 continue 能力不因此删除。

审批回复仍绑定 approvalId 与原操作身份。拒绝时可携带用户说明（非空且不超过 8000 字符），说明只追加到本次 USER_DENIED 工具回执并进入模型下一次请求，不排成新的用户消息；批准不能携带拒绝说明。停止/过期的审批不能接纳迟到说明，取消结果保持 USER_INTERRUPTED。TUI 使用上下键与 Enter 操作三选项菜单，拒绝并回复时切换专用输入状态，普通字符不批准工具。工具权限的全局默认与当前会话入口分开，修改仍遵守原有空闲与角色权限边界。

待排队消息由 Inbox 持久化拥有，删除只撤回尚未进入请求的消息；已接纳或已执行消息不能伪装撤回。对某条排队消息执行引导，将截至该条的待排队前缀一起转为 steer，保留输入身份和先后次序；在下一完整请求边界加入上下文。UI 先显示这些已接纳引导消息，实际模型请求仍遵守完整工具边界。

外观、字号、缩放、快捷键与输入偏好独立于 Agent 装配；仅修改 preferences 的事务可在运行中写入同一全局配置，不重建 Agent 或中断工具。其他配置更新仍遵守装配与运行边界。命令失败的脱敏原因写入应用目录 logs/runtime-<pid>.log；UI 只显示简短操作反馈，不将堆栈或原始异常常驻顶部。

项目指引的来源以实际目录显示，用户目录下用 ~/ 相对形式；不使用 project-scope-N 等数字别名。完整祖先链仍按由远到近的顺序读取，工作树位于仓库内部时明确展示主检出与工作树两条来源。

启动工作目录由显式 workspace 参数、QUIFOX_WORKSPACE、进程当前目录依次确定；已保存的全局 workspace 不覆盖本次启动。公开配置的 workspace 投影为本次 Host 的默认目录，缺省资源查询和缺省创建使用同一目录。Desktop 显式请求自动日期目录时与启动目录区分。单个 Host 可创建不同工作目录的会话，各会话始终按自身目录读取祖先配置与项目指引；选择其他目录不创建第二个 Host，也不修改已有会话。

resources 返回所选目录继承后的脱敏 config 投影，让无会话的模型、思考和权限控件显示实际项目默认；显式 workspace:null 从当日自动工作目录的最近已有祖先读取配置与资源，返回实际预览目录，不创建日期目录。plugins 等管理查询复用这个已有目录；自动创建后切换为会话的实际目录。两者只读取配置，不把 UI 的项目选择写回全局文件或改变 Host 启动目录。只读检查发现全局配置缺失时在内存使用默认值，不重新创建文件；首次 Host 初始化与明确配置写入仍拥有落盘职责。

无会话的 plugins 查询只读取继承配置与安装目录，不构造 Agent，不要求模型容量或可执行连接；此时没有实际会话装配，plugins 数组为空。已存在会话的查询才返回实际插件顺序。模型容量缺失不阻止查看安装配置和历史观测；创建、执行与配置写入仍按各自合同校验候选组合。

Desktop 可注入展示适配器，Host 才装配独立 PresentationPlugin；TUI 不注入。插件贡献本轮 RequestContext，不写永久系统消息；子会话按实际执行宿主重新装配。open_view 属于只读展示，支持任意目录中的文件，相对路径以会话工作目录解析；不新增目录白名单或要求创建会话。路径解析为实际文件，图片/视频只返回资源身份与路径，正文读取有界。展示请求绑定会话和 operationId，UI 确认后返回真实标签或外部目的；停止、断连、超时明确失败，未知恢复遵循 Checkpoint，不宣称请求未发生。GUI 项目读取/目录树可按用户选择目录查询。

浏览器可执行的输入解析与接收者补全从公开 `@quifox/shared-runtime/input-routing` 子入口导入，工具展示从 `presentation` 子入口导入；这些入口没有 Node I/O。总入口拥有 Host 装配，仅在 Bun/Node 宿主执行；前端协议 DTO 使用 type-only 导入。

创建会话的 workspace 为路径时使用该目录，省略时采用 Host 的工作目录；显式 null 表示自动分配独立工作目录，供 Desktop 未选目录的新对话使用。自动目录在实际创建时以宿主本地日期组织为 `<应用资料根>/workspaces/YYYY-MM-DD/new-chat`，同日冲突以 `-2`、`-3` 递增，使用原子 mkdir 避免并发合并。相同创建身份的重试仍返回原会话与原目录，跨午夜也不再创建目录。前端不自行分配目录或维护第二份会话身份。

Observability 插件通过普通 Hook 采集事实，Host 写入已有 journal；summary/evaluate 命令读取完整归档事实，不从 UI 裁剪轨迹反推指标。比较仅统计显式 variant 与 Eval，不宣称已有批量任务集执行器。公开组合快照包括当前插件顺序、最终工具目录和 system/context 来源，先脱敏再持久化。

只读 summary 刷新其他 Host 的 journal；最近未闭合 run 在持久化运行状态和有效执行租约共同成立时显示运行中，否则显示终态未知。评测写入需要当前会话执行租约；目标校验使用完整事实，不受近期展示窗口限制。

组合快照先对完整值脱敏，再限制每类最多 100 项、元数据 128 字符、工具描述 512 字符与总正文 65,536 字符；截断与真实工具总数明确标记，不在每轮观察日志重复写入无界 MCP 描述。summary 保留完整统计/比较，只投影最近 50 个 run 和有界调用/文本；totalRuns 与 displayTruncated 说明展示边界，原始请求与 journal 事实不由 UI 裁剪。

MCP 启停只有条目的 enabled 字段；全局 .quifox/config.json 提供默认，工作目录祖先配置以相同字段覆盖，最近作用域优先。GUI/TUI 共用 Host 的 mcp-set-enabled 命令写入指定全局或当前目录文件，不存在额外禁用列表或迁移字段。目录只覆盖启停时保留连接来源与信任边界，不因此将已信任全局连接变成未信任项目连接。Skill disabled 按 catalog 身份过滤运行装配，资源管理仍显示完整目录以便重新启用。

可选插件的启停记录在同一配置的 plugins 映射，按目录链逐字段继承；MCP 仍由连接条目的 enabled 拥有。Memory 插件启停与 memory.enabled（读取/注入）、memory.generate（生成）分别控制模块与内部行为，不替换原合同。PluginActivationPlugin 在构造 Agent 前选择真实对象，禁用或未安装插件不注册或初始化，不热拆活动运行。installedPlugins 是内置扩展的安装清单，默认包含随 Host 提供的全部扩展，目录层声明时替换清单；安装/移除写入相同作用域配置，不删除历史与用户数据。当前插件市场来源是内置目录，安装表示接入已有模块，不宣称下载外部软件包；外部来源未实现。市场仅筛选全部插件/已安装插件，我的插件筛选全部/启用/禁用。已配置 MCP 连接也进入我的插件，核心授权、会话与恢复 Hook 只在装配详情展示，不作为可停用扩展。

模型目录使用六小时缓存有效期，同一 Host 内过期查询与小时后台检查合并拉取，失败保留目录并退避五分钟；共享缓存在宿主启动时读取，当前刷新去重不跨宿主。后台目录更新在下一次空闲配置刷新重建组合，正在执行的请求保持稳定。显式模型配置优先。外观支持独立字号和缩放；快捷键绑定需互不冲突，默认字号 18px、压缩安全余量 10,240 Tokens。设置显式读取 memory.md 的只读投影，即使 Agent 记忆注入关闭也可检查文件；不改变 state.json 的权威 owner。

模型能力按显式配置和 Models.dev 接口资料解析；不以思考布尔值生成通用档位或供应商默认，不建立逐模型档位表。接口未暴露的档位保持未知。全局初始思考偏好为 high，可通过 preferences.reasoningEffort 修改；会话/角色/模型的明确选择优先，自动 high 只在已知支持时应用。供应商协议参数转换归模型插件，Host 不拼装专有字段。

`model-catalog` 提供支持 Chat 协议的供应商与其模型目录，元数据与连接配置分开；显式刷新由 Host 从 Models.dev 获取并原子缓存，不发送模型密钥，不重启正在运行的 Agent。网络请求有超时，Host 关闭取消未完成的目录请求。查询不创建会话，失败不替换已保存连接；供应商目录可筛选或使用自定义 Chat 配置。

- 默认配置、会话与运行时 Memory 位于用户 `.quifox`；配置为 JSON，原会话与真实事件为 JSONL。恢复只忽略未完整写入的最后一行，已闭合损坏行明确失败。关键状态在发起模型/工具前落盘；Session、执行记录与输入接纳以同一状态记录保存，避免分别推进。
- 每个会话的状态写入串行化。输入先写候选 Inbox/来源/标题，成功后才进入可执行内存队列；失败提交不能留下可恢复的幽灵消息。已完成关键写入后的观察失败不撤销接纳；Session 保存失败不提前推进输入来源映射。
- 新建可携带调用方生成的 UUID sessionId，相同创建身份与参数在并发或重启后返回原会话，参数冲突明确拒绝；创建状态已提交后观察失败不撤销成功。两种 UI 在创建或输入回执不确定时保留同一身份进行重试，成功确认后才为下一份输入生成新身份。JSONL 命令校验保留输入原始空白，不以 trim 改写消息。
- JSONL 初始状态完整保存，后续状态以版本化差量记录同一次事务的全部变化，绑定上一 metadata revision；完整旧记录仍可读，不自动重写用户归档。读取逐行重建并校验不可变状态，可释放旧状态而保留最新视图及事件；归档消息提取保留首次出现的物理行号。增量基底、操作或闭合行损坏明确拒绝；恢复仍仅忽略不完整 JSON 尾。Memory source read 返回该行的真实物理 JSONL，不伪造展开后的原文。
- 归档校验对同一次不可变 replay 内的共享对象复用验证结果，仍检查每条历史状态的字段、输入格式与身份；最后装配为可运行会话时重新完整校验和复制，不把校验缓存用于外部可变对象。
- 待接纳请求的 prepared 前缀按上一状态历史中的消息范围引用；不在基底中的新消息仍原样保存。引用只能在同一会话、相同 revision 的基底内展开，不跨会话借用或从新配置重新拼接请求；未闭合工具边界与原始输入保持恢复合同。
- 旧工作目录、模型或 Agent 配置失效时，保留已验证归档的只读会话投影，明确不可执行，不妨碍宿主创建其他会话；修复后可重新装配。已闭合归档的语法、身份、序列或输入格式损坏仍拒绝，不能以目录不可用掩盖归档损坏。
- 同一资料目录允许多个宿主，每个宿主正常启动创建自己的主会话。会话树通过独立跨进程租约保持一个写入/执行 owner，外部会话可只读刷新；指定同一会话的竞争写入明确拒绝。共享配置与 Memory CAS 使用短事务锁，不依赖目录独占。同一会话串行消费整个 Agent 流和异步收尾后再启动 Queue。Steer 在完整请求边界加入；停止信号不伪造副作用回滚。
- 只读快照、资源、插件管理与历史观测读取当前配置投影或已有会话事实，不为观察重新装配已有 Agent；因此项目模型配置暂时不可执行也不阻断管理和归档读取。新执行及配置写入接纳前核对共享文件，闲置时先完成候选组合后采用外部更新。正在运行或有后台任务时延后重组，保持已接纳执行的配置与工具合同；进入闲置后的新执行重新读取，不用旧配置启动新的闲置轮。
- continue 复用未完成原工具轮，已完成回执跳过，未知结果只在 retrySafe 保证或真实核实后重试。replan 保留已确认结果，对未启动/未知调用补明确回执后交给模型。重启时运行中的操作保持未知，不能从日志缺席推断成功或未执行。
- 子任务恢复保留 taskId、父子 Conversation 能力归属与真实终态；待接纳或未完成的新输入优先于旧 run-end 回复，不能用旧结果掩盖已接纳任务。被动 Fork 不调用模型；后续消息从相同子会话继续。父轨迹接收带子身份的真实事件，不把子回复注入父消息历史。
- 人类输入的 `/spawn [--fork] [数量] [提示词]` 在共享 Host 创建待机子 Agent，缺省一个，单批数量为 1–100；默认空历史，--fork 时同批使用同一安全会话前缀，提示词作为持久化任务说明供唤醒时使用，创建不调用模型。返回真实会话/taskId 与会话树内稳定 @ 名称；模型工具创建的子 Agent 同样生成/返回名称，重名明确拒绝。相同输入身份重试返回已有子任务，参数冲突拒绝。部分创建失败返回已成功的身份，不伪装整批回滚。
- 批次安全前缀与输入身份在同一私有接纳记录中提交，先于能力初始化和任何子会话创建；零创建成功或首个子会话写入前崩溃后，仍从同一原始前缀重试。私有接纳记录保留在归档，不进入公开事件订阅和 SessionView。
- 人类输入以 Agent @ 开头时，连续接收者共用后续正文，正文后出现新接收者开始下一组；解析当前会话树内子 Agent 的名称、会话/taskId 或唯一前缀，不路由邮箱、转义和代码中的 @。全部分组先校验目标与非空正文，再按组逐个持久接纳；同身份重试不重复执行，逐个报告成功与失败，待恢复目标明确拒绝。普通输入、模型工具输入和其他会话通信不自动解析这套人类语法。
- 父工具向待恢复子会话发送消息时明确拒绝，先 continue/replan 后重发；已接纳消息若在等待期间遇到停止则保留队列，不越过原请求。子执行者只领取最早已接纳输入。Fork 的来源映射只复制实际保留前缀，避免父后续消息的局部 ID 污染子消息来源。
- 工具事件与 replan 回执使用会话、持久化工具批次与调用 ID 组合的 operationId 关联；重复 call ID 不跨批次覆盖历史。持久化租约使用 proper-lockfile 的 mkdir/mtime 心跳；租约失效后后续写入失败关闭，退出释放所持租约，崩溃租约在十秒陈旧期后可竞争回收。不主动删除其他宿主的锁。算法边界与依赖依据见 [官方说明](https://github.com/moxystudio/node-proper-lockfile#design)；本阶段使用本地文件系统，不宣称分布式或网络文件系统一致性保证。
- operationId 位于工具开始、结果和恢复事件的顶层。压缩观察事件只在发布成功后登记；重启从持久化检查点补发缺失观察，不重新生成摘要，也不让观察失败撤销已提交状态。
- 每个工具有独立 policy。审批绑定当前会话、原调用身份和最终参数；拒绝、停止、失效授权不执行工具。授权不直接修改历史或绕过普通执行入口。
- 用户可以在创建会话或闲置时通过 session-config 明确选择 ask/allow；不指定时使用当前目录有效配置的默认审批。该覆盖持久化到会话，不写入全局配置。角色与父权限施加的 deny 上限不可提高；allow 仅跳过询问，不扩大工具、路径或角色范围。运行及后台任务期间拒绝切换。
- 全局 JSON 配置可被工作目录祖先链的 `.quifox/config.json` 部分字段覆盖，顺序为全局、文件系统根、各祖先、当前目录；相邻层对 model/compaction/memory/preferences 按字段合并，对 models/mcp 按身份覆盖，最近配置优先。项目指引同样读取完整祖先链，不止 Git root；全局文件只读取一次。有效来源可见，密钥不进入公开投影。
- 显式 `--root` 选择独立用户资料目录；默认用户 `.quifox/config.json` 不作为项目祖先层重新读入，以免把另一资料目录的连接或授权覆盖进来。项目自己的 `.quifox/config.json` 继续正常继承。
- 项目选择的模型 URL origin 必须已在用户全局 model/models 连接中声明，否则装配前明确拒绝，不发送提示词或归档。项目层把连接改到不同 origin 时不继承先前层的 apiKey/providerOptions；同 origin 路径变化仍可继承。目标凭据需显式配置，MCP 目录信任不等同模型跨服务授权。
- `model` 保存默认 Chat 连接，`models` 保存带稳定 id 的额外连接；会话持久化 modelId/思考覆盖，默认配置更新不改变其他会话的选择身份。Agent 定义从用户 `agents/*.md`、祖先 `.claude/agents/*.md` 与 `.quifox/agents/*.md` 读取，最近同名定义覆盖；支持 name/description/model/tools/disallowedTools/permissionMode/effort。permissionMode 只支持 default（当前用户策略）、plan（只读工具）、dontAsk（拒绝需审批工具）；acceptEdits/bypassPermissions 与其他未支持字段明确列入问题，不静默升权或宣称全量 CC 兼容。
- 子 Agent 的有效模型顺序为本次指定、Agent 定义、父会话继承；`inherit` 继承父选择。思考同样派生且按目标模型支持列表校验。模型/Agent 名称错误在创建前返回业务错误。子工具范围与父实际已注册范围相交，deny 优先；重组时当前角色限制与持久化工具上限继续相交，不能通过修改定义扩大既有权限。默认审批跟随当前用户配置，会话中人类明确设置的 ask/allow 优先，持久化角色限制只能进一步 deny；子定义不能提高父审批权限。指引正文经 RequestContext 提供，不冒充人类消息。
- 容量由模型资料与明确配置解析，用户 context 不能抬高已知模型上限；输出预留、安全余量、compactTokens 与输入上限共同收紧压缩。请求估算包含临时指引、Skills、Memory 与工具定义；无效预算提前失败。摘要仅在完整工具边界提交，原文归档保留。
- 复用现有两阶段 Memory。Host 实现 owner 隔离的状态 CAS、原文 archive 与后台调度；临时记忆经 RequestContext 投影，不成为人类证据。生成与读取失败保持真实状态，不由 UI 创建替代记忆。
- Memory 读取与生成采用当前会话的有效配置；全局关闭为上限，项目只能进一步 opt-out。关闭读取时不自动读取/投影 Memory，也不暴露 memory_* 工具；关闭生成的会话不进入其他会话触发的提取候选。显式的其他会话列表与通信工具仍遵守自身合同。
- 指引从全局与项目祖先作用域读取；技能目录读取元数据，正文/引用按需加载，资源的真实路径限制在所选技能根目录。脚本经普通进程工具和审批。MCP 使用标准 SDK 与相同工具入口；单 Agent 停止取消其发现/连接等待，共享连接仍由 Host 管理。退出先取消运行及连接握手，再等待已接纳操作与持久化收尾，重复关闭等待同一个清理过程。连接意外断开后状态失效，可重新连接。
- 未授权项目 MCP 不参与工具装配，仍展示未授权状态；MCP 发现失败移除该 server 本次部分注册的工具并提供错误观察，普通 Agent 轮可继续。显式连接成功后重新装配闲置会话，让固定的工具注册表采用当前发现结果；活动运行与后台任务期间拒绝重装，不运行未授权工具。
- MCP 状态标记实际配置来源；祖先项目层声明同 ID 时，即使连接内容与全局相同，也显示为项目配置。UI 只提供明确全局条目的全局删除操作，不用删除全局配置假装删除项目覆盖。
- 消息开头的 `/skill-name` 或 `$skill-name` 选择最近作用域的技能，`$catalog-identity` 可明确选择其他来源；UI 卡片保留准确身份，内建斜杠命令与同名技能冲突时用 `$` 选择。选择只读取技能正文，不自动执行脚本或改变工具权限。
- 公开配置省略密钥；错误只提供稳定公开描述，事件投影对已知配置秘密脱敏。切换连接 URL origin 时，未显式重填的 apiKey/providerOptions 清除，同 origin 路径更新保留。观察失败不改变业务结果；关键归档失败阻止尚未开始的 I/O。测试不写用户真实数据目录。
- `resources` 按目录读取 Skills 元数据、指引来源、Agent 定义、Memory 预览与脱敏配置，不创建会话或请求模型；`plugins` 在已选会话时枚举实际组合对象，未选会话时只读取所选目录的安装与启停配置。同一绝对技能根只发现一次。
- 全局 `snapshot` 提供配置文件事实的不可逆 revision，GUI 据此刷新插件投影并保持选中插件；运行事件序列单独驱动观测更新。revision 不携带配置正文、秘密或设备路径。
- 已知全局与项目连接秘密在工具结果进入 Checkpoint/Session 前脱敏，保持共享结果对象身份；MCP 错误不会把认证内容送入下一轮模型或 UI。连接失败提供稳定描述，不展示 SDK 原始错误。
- UI 快照按结构观察限制数量，并对消息、事件、差异、任务、审批、待接纳消息、Memory 与目录元数据设置字节预算；实时事件与新建/配置回执采用相同显示投影，已失效目录的只读历史也遵守该预算。较长内容明确标记预览截断，差异片段不加入伪造文件行；操作身份与终态保留，完整原始值仍在归档。sidecar 对超过桥接预算的响应返回普通错误，不用单帧致命错误关闭引擎。公开视图区分模型有效思考默认、会话显式覆盖与有效审批模式。
- 配置在候选校验阶段限制公开 JSON 总字节，超过预算在落盘前拒绝，不能提交后才报显示失败。显示层保留普通操作身份；超过 256 字符的外部不透明 ID 使用完整值的稳定 SHA-256 标识关联，原始 ID 继续保存在模型与归档中，不按相同前缀裁剪造成碰撞。TranscriptMessage 的 operations 由 Host 提供调用身份与完整操作身份的关联，UI 不从已投影的字段重新拼接身份；失效目录与重复展示投影也保留同一关联。
- 配置/模型资料更新先完成全部候选组合，再落盘并切换已有会话。配置命令与 MCP 连接在首次异步等待前独占接纳门，并等待已接纳命令收尾；共享文件刷新不能提前释放此门。更新期间禁止其他配置、新模型、输入与 Memory 生成接纳；活动操作不允许切换。未改动的隐私字段保留，可选容量/压缩覆盖用 null 清除。Memory 完成、已提交压缩与 replan 配对回执提供真实更新事件；退出等待这些发布和后台续租收尾。
- 文件使用平台路径 API，进程使用参数与标准 Host API，退出收口子进程、后台任务、子 Agent 和连接；不建立跨平台测试矩阵、沙箱或默认任务总预算。
- Shell 命令由独立轻量 supervisor 持有命令进程组，Host 通过 stdin 管道维持其生命周期；正常取消或 Host 崩溃后的 EOF 均请求终止，必要时强制结束命令组。编译 sidecar 支持同二进制 supervisor 唯一入口，开发 Host 使用独立入口文件与当前 Bun/Node 执行器；共享 supervisor 模块没有入口副作用，EOF 后不再启动命令。未知 shell 语法保持执行风险并请求授权，不把字符串分类当作 OS 沙箱；恶意自行脱离进程组的命令不提供隔离保证。
- 文件审批提供真实源内容与候选内容差异，批准同时绑定规范化目标与源内容指纹；审批等待期间源变化或软链改向使授权失效。工具成功回执保留真实 before/after 投影，超长内容明确截断；不从模型文案推测已修改文件。
- Git 工作目录的命令执行前后观察文件变化，减去已有未提交编辑；命令失败后的实际修改仍展示，不假设失败即回滚。观察只限工作目录内、最多百个文本文件与单文件 1 MB，超出明确标记；非 Git、二进制、进程期间 commit 清理掉的状态与外部并发修改不提供完整归因保证。原生编辑工具继续提供确定的自身前后内容，同轮同文件聚合首个 before 与最后 after。

工具链为 Bun + strict TypeScript；验证继续使用 Vitest/Node。DeepSeek 默认模型/容量的来源为 [官方模型文档](https://api-docs.deepseek.com/quick_start/pricing/)，models.dev 资料由 Host 显式刷新/缓存；资料可见不代表真实链路通过。

- LangChain 是独立的 Skill 集插件。启用后通过已有 Skills 发现/加载/读取工具提供随应用打包的技能与引用文件；停用或移除后不再发现。原 LangGraph Skill 名称与 API 原文保留，插件展示名统一 LangChain。该插件不注册业务执行工具、不创建另一套工作流执行器、不安装 Python/TypeScript 框架依赖、不自动运行文档中的命令。其工作流脚本不能假定由 QuiFox 工作流支持层直接执行。

TUI 的 npm 分发名为 `quifox`，命令同名；包只拥有安装入口与同一 TUI/Host 的 Node.js 22.12+ ESM bundle，不要求用户另装 Bun，不发布开发 workspace 或通用框架包。包携带 shell supervisor 的两个相邻入口、根 LICENSE、Memory LICENSE/NOTICE 与实际打包依赖的许可证；不包含配置、会话、源映射或构建输入路径。Bun 继续拥有开发构建与原生 CLI 编译，npm 安装不创建第二套运行逻辑。生成 manifest 保持 private，正式发布另行授权。
