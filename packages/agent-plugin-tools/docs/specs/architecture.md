# 工具入口与衍生插件

提供普通工具入口及其配套衍生插件。Core 不保留入口名称、目录分组、暴露模式或特定信封解析。

- 查询未知插件返回空 tools；未知执行目标返回 TOOL_NOT_FOUND，不选择其他插件或执行业务。
- 主插件提供一个普通 Tool；名称可配置，默认 `plugin`。其查询结果由后续从属插件的 afterTool 按调用参数补充，不无条件暴露所有工具。
- 从属插件仍是普通 AgentPlugin，按数组顺序位于主插件之后。缺少主插件时自行退出注册；不自动排序或级联卸载。
- 后置筛选移除主插件时，从属项不被框架级联删除，但不得映射其调用或补充其他工具的结果；使用本次 Registry 的原定义身份核对入口，同名或同 Schema 不足以证明绑定。
- 衍生适配只声明位于主插件之后；原插件的 after 缺失或已指向主插件时可适配，其他 after 约束显式拒绝，不静默覆盖或引入多依赖排序。
- 从属插件在 beforeModel 隐藏所适配的业务定义，在 beforeTool 校验自己的入口分支并映射到真实工具；原插件的业务前置钩子读取映射后的目标。查询定义从本次唯一 Registry 导出，不维护另一份可调用注册表。
- 归属、参数和查询/执行组合由这一组具体插件约定。入口改名时共同调整；不声明自动兼容未知的搜索或查询格式。
- 模型历史保留原调用 ID 和入口名称。映射后的目标由唯一执行入口绑定其 prepare、policy 和 execute，禁止直接调用 handler、递归 Run 或嵌套执行器。
- 不把目录查询成功当业务成功。afterTool 同时更新 data 与模型读取的 content，不补充失败结果或改变执行统计。
- 验证无默认工具、改名、多个扩展顺序补充、按参数查询、所有权拒绝、直接调用拒绝、实际目标的参数修复/权限、取消与历史身份。

- 具体工具自行实现 prepare/execute，并决定参数错误是在工具内部形成 ToolResult，还是抛错进入 Outcome。本包不安装通用修复或错误反馈层。
- 映射后的最终目标缺失时，Core 唯一执行入口返回 `TOOL_NOT_FOUND`，结果继续经过 afterTool；本包不维护第二套缺失目标策略。
